# johntrandall/homebrew-tap

Personal Homebrew tap.

## Available formulae

- **`zk-reindex-launchd`** — Auto-reindex zk notebooks on macOS via a LaunchAgent. [`upstream`](https://github.com/johntrandall/zk-reindex-launchd)

## Install

```bash
brew tap johntrandall/tap
brew install johntrandall/tap/zk-reindex-launchd
```
